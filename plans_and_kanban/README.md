# OfficialConnect plans and handoff

This folder is the shared planning surface for OfficialConnect work. It is
intended to be readable by both Codex and Muse.

- `CURRENT_STATE.md` records the verified state carried forward from the
  referenced Codex task.
- `KANBAN.md` is the active queue, with completed, blocked, and next actions.
- `MUSE_HANDOFF.md` is the execution brief for the next substantial Muse run.
